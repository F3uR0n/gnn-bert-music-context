# GNN-Based BERT for Understanding Context from Music

## Overview
This repository contains a hybrid neural network framework designed to understand musical context by merging structural audio data with semantic text descriptions. It utilizes a Graph Neural Network (GraphSAGE) for audio structure processing and a fine-tuned DistilBERT model for natural language metadata encoding.

Note on Source Code and Execution
Please note that the core development, training, and evaluation for this project were conducted interactively within Jupyter Notebooks to facilitate exploratory data analysis and visual output generation.

To comply with the src/ directory submission requirements, the modular tasks have been exported as .py source scripts. The execution hooks in train.py and evaluate.py direct towards the notebook pipeline to handle dynamic memory allocation and data retrieval.

Additionally, due to dynamic data retrieval (via wget and the HuggingFace datasets library for FMA and MusicCaps) within the code execution flow, the data/raw/ directory is kept empty by design. The required simulated graph samples for validation are generated by the code and located in data/processed/.

Setup & Usage
Install the required dependencies using:

Bash
pip install -r requirements.txt
System hyperparameters and dataset configurations (including FMA and MusicCaps) can be viewed and configured in config.yaml.

All data downloading, feature extraction, and graph building are handled automatically in the initial cells of the provided notebooks.

To view training procedures and ablations, run the notebooks in sequence (task_1 through task_4).

For a live, end-to-end prediction, execute notebooks/demo_context.ipynb.
